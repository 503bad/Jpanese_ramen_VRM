# インストール手順

## 1. 自動インストール(install.bat)

1. 配布物を任意のフォルダに展開します(ゲームのフォルダの中である必要はありません)。
2. `install.bat` をダブルクリックします。
3. ゲームのインストール先は自動で検出されます:
   - レジストリから Steam の場所を取得 → `steamapps\libraryfolders.vdf` の全ライブラリを確認
   - `appmanifest_4968640.acf` の `installdir` から `RealRamenSimulator-Win64-Shipping.exe` の存在を確認
   - 複数見つかった場合は番号で選択、見つからない場合はフォルダ選択ダイアログが出ます
4. 書き込む予定のファイルが一覧表示されるので、確認して `y` を入力します。

### オプション

| オプション | 説明 |
|---|---|
| `-DryRun` | 何も書き込まず、予定だけ表示する |
| `-GamePath "<フォルダ>"` | ゲームのフォルダを明示指定(ルート / `RealRamenSimulator` / `Binaries\Win64` のどれでも可) |
| `-Yes` | 確認を省略する |

### インストールで行うこと

- UE4SS が既にあれば(他の MOD に同梱されていたものを含む)**そのまま使い、上書きしません**。
  無ければ**配布物に同梱の UE4SS** を導入します(利用者が別途入手する必要はありません)。
- `<UE4SS の Mods フォルダ>\RamenVRM\` に MOD 本体と `enabled.txt` を置きます(`mods.txt` は書き換えません)。
  - UE4SS の配置により Mods フォルダは `Binaries\Win64\ue4ss\Mods` または `Binaries\Win64\Mods`。
- `ドキュメント\RamenVRM\models` を作ります(VRM を置く場所)。
- 置いたファイルの一覧を `%LOCALAPPDATA%\RamenVRM\install_manifest.json` に記録します(アンインストールで使用)。
- このMODが置いたものではない既存ファイルがある場合は、上書きせずに中止します。

## 2. 同梱の UE4SS について

UE4SS(https://github.com/UE4SS-RE/RE-UE4SS 、MIT ライセンス)は MOD をゲームに読み込ませるための土台です。
配布物には UE 5.7 対応の版(`experimental-latest`、版は `licenses\UE4SS_bundle_README.md`)を同梱しています。

- 同梱するのは UE4SS 本体と設定だけです。UE4SS 付属のサンプル MOD(チート機能・コンソールの有効化など)は
  含めず、`mods.txt` ですべて無効にしています。
- 既に別の MOD で UE4SS を入れている場合は、そちらを使います(同梱版は使いません)。
- `dwmapi.dll` はゲームに UE4SS を読み込ませるためのファイルです。ウイルス対策ソフトが警告することがあります。
- ライセンス文は配布物の `licenses\` にあります。

## 3. VRM の配置

1. 配布物の **`install.bat` と同じ場所にある `models` フォルダ**に `.vrm` ファイルを置きます(何体でも可)。
   `install.bat` がこのフォルダの場所を記録し、MOD はここを直接読みます(コピーはしません)。
   インストールした後に追加しても構いません。配布物のフォルダを移動したときは `install.bat` を実行し直してください。
   (以前の版の置き場所 `ドキュメント\RamenVRM\models` も引き続き読みます)
2. ゲームを起動すると、自分のキャラクターが VRM で表示されます(ゲーム開始の数秒後に切り替わります)。

### 見た目を切り替える(ゲーム中いつでも)

- **F6 で次、F5 で前**の見た目に切り替わります。順番は「元の見た目 → VRM(ファイル名順)」です。
- **F7** で表示方法を切り替えます(ライティングあり ⇔ アニメ調)。
- 選んだものは `config.ini` に保存され、次回の起動でも使われます。
- ゲーム中に models フォルダへ追加した VRM も、次に F5 / F6 を押したときに選べるようになります。
- ロッカーのカスタマイズ画面のプレビューには VRM は写りません(元の見た目のまま表示されます)。

### マルチプレイ(フレンドと見せ合う)

**相手も同じ VRM ファイルを自分の models フォルダに入れていれば**、お互いの VRM が見えます。

- MOD はモデルのファイルを送りません。Steam の「プレイ中の状態表示(リッチプレゼンス)」に、
  使っているモデルの ID(ファイルの中身から計算した値)とゲーム内の名前だけを載せます。
- 相手の MOD は、自分の models フォルダに同じ ID のファイルがあれば、そのキャラクターを VRM で表示します。
  ファイル名は違っていても構いません(中身が同じなら同じモデルとみなします)。
- **Steam のフレンド同士**でのみ動きます。フレンドでない人、MOD を入れていない人、同じファイルを持っていない人には、元のキャラクターが見えます。
- モデルの受け渡しは各自で行ってください(モデルの利用条件に従ってください)。
- 共有したくない場合は `config.ini` の `share_with_friends = 0`。


- 一人称視点では、カメラに映り込まないよう VRM の頭部分を自動で隠します。

### config.ini(ドキュメント\RamenVRM\config.ini)

初回起動時に自動で作られます。UTF-8 のテキストで、変更はゲームの再起動後に反映されます。

| 項目 | 既定 | 説明 |
|---|---|---|
| `model` | 空 | 使う VRM のファイル名(models フォルダの中)。空なら最初に見つかったもの、`none` なら元の見た目。ロッカーで選ぶと自動で書き換わる |
| `enabled` | 1 | 0 にすると MOD を止める(元のキャラクターのまま) |
| `spring_bones` | 1 | 揺れもの(髪・スカートなど) |
| `auto_blink` | 1 | 自動まばたき |
| `shading` | lit | 表示方法。`lit` = 光の当たり方を反映 / `unlit` = アニメ調。ロッカーの F7 でも切り替わる |
| `share_with_friends` | 1 | マルチプレイで Steam のフレンドとモデル ID・ゲーム内の名前を共有する |
| `hide_head_in_first_person` | 1 | 一人称で頭を隠す |
| `double_sided_all` | 0 | VRM で片面のマテリアルも両面表示する(重くなる)。VRM で両面指定の部分(髪など)は常に両面 |
| `reverse_faces` | 0 | ポリゴンが裏返って見えるときだけ 1 にする |
| `material` | 空 | 表示に使うマテリアルの手動指定(空なら自動で探す)。調整用 |
| `material_texture` | 空 | 上のマテリアルのベースカラー用テクスチャパラメータ名。調整用 |

### うまく表示されないとき

ゲームの `RealRamenSimulator\Binaries\Win64\ue4ss\UE4SS.log` に、行頭が `[RamenVRM]` の記録が出ます。
問題を報告するときはこのファイルを添えてください。何かに失敗した場合、MOD はそのキャラクターを元の表示に戻して停止します。

- マルチプレイでは、VRM の利用許諾で**再配布が許可されているモデルだけ**を他のプレイヤーへ送ります。
  許可されていないモデルは自分の画面にだけ表示され、他の人には元のキャラクターが見えます。
- `vrm_inspect.exe <file.vrm>` で、モデルの利用許諾と送信可否を確認できます。

## 4. アンインストール(uninstall.bat)

`uninstall.bat` を実行します。インストール時の記録にあるファイル**だけ**を削除します。

- UE4SS は、このインストーラが導入した場合のみ削除します(元から入っていた場合は残します)。
- VRM・設定(`ドキュメント\RamenVRM`)とキャッシュ(`%LOCALAPPDATA%\RamenVRM`)は、削除するか確認します
  (`-RemoveUserData` で確認なしに削除、`-Yes` のみなら残します)。
- UE4SS が実行時に作るログ等(`UE4SS.log` など)は記録に無いため残ることがあります。不要なら手で削除してください。

## 5. 手動アンインストール

インストール記録が無い場合(記録ファイルを消した等)は、次を手で削除してください。

1. `<ゲーム>\RealRamenSimulator\Binaries\Win64\ue4ss\Mods\RamenVRM`(または `...\Win64\Mods\RamenVRM`)フォルダ
2. 不要なら `ドキュメント\RamenVRM` と `%LOCALAPPDATA%\RamenVRM`
3. UE4SS 自体を消す場合は、他の MOD が UE4SS を使っていないか確認してから
   `Win64\dwmapi.dll` と `Win64\ue4ss`(古い形式では `Win64\UE4SS.dll` 等)を削除

ゲームの整合性に問題が出た場合は、Steam の「ゲームファイルの整合性を確認」で元に戻せます。
