# Ramen VRM MOD

Japanese Ramen Simulator(Steam AppID 4968640)のプレイヤーキャラクターを、
**各プレイヤーが自分で用意した VRM モデル**で表示する非公式 MOD です。

- VRM 0.x / 1.0 に対応(読み込みは MOD 内で自前実装。エンジンプラグイン・UE エディタでの変換は不要)
- ゲーム本体の動き(移動・アクション)をそのまま VRM の骨格へ移して表示
- 揺れもの(髪・スカートなど、VRM SpringBone)と自動まばたき
- 一人称視点では、カメラに映り込まないよう VRM の頭部分を自動で隠す
- VRM 用の専用マテリアルを同梱(ライティングあり / アニメ調を切り替え可能)
- ゲーム中に **F5 / F6** で見た目を切り替え(元の見た目 ⇔ 各 VRM)
- マルチプレイ: Steam のフレンド同士で、**相手も同じ VRM ファイルを持っていれば**お互いの VRM が見える(ファイル自体は送らない)

## 使い方

詳しくは [docs/INSTALL.md](docs/INSTALL.md)。

1. 配布物(`RamenVRM_<版>.zip`)を任意のフォルダに展開し、`install.bat` を実行します。
   - ゲームのインストール先は自動で検出します(Steam のライブラリを検索)。
   - UE4SS(MOD をゲームに読み込ませる土台)は配布物に同梱しています。既に入っていればそれを使い、上書きしません。
2. `install.bat` と同じ場所にある **`models` フォルダ**に `.vrm` ファイルを置きます(何体でも可。インストール後に追加しても可)。
3. ゲームを起動すると、自分のキャラクターが VRM で表示されます。

| キー | 動作 |
|---|---|
| F6 / F5 | 次 / 前の見た目に切り替え(元の見た目 → VRM をファイル名順) |
| F7 | 表示方法の切り替え(ライティングあり ⇔ アニメ調) |

選んだモデルと表示方法は `ドキュメント\RamenVRM\config.ini` に保存され、次回も使われます。
元に戻すときは `uninstall.bat` を実行します(インストール時に置いたファイルだけを削除します)。

## 注意

- 非公式 MOD です。ゲームの開発元とは関係ありません。ゲームのアップデートで動かなくなることがあります。
  その場合も、MOD は失敗を検出すると元の見た目に戻して停止するようにしています。
- VRM モデルの利用は、各モデルの利用条件(VRM の meta に記載)に従ってください。
  マルチプレイで相手に見せるには相手も同じファイルを持っている必要があります。モデルの受け渡しは利用条件の範囲で各自行ってください。
- マルチプレイでは、Steam のリッチプレゼンス(フレンドに見える状態表示)に「使っているモデルの ID」と「ゲーム内の名前」を載せます。
  不要なら `config.ini` で `share_with_friends = 0` にしてください。

- 開発の経緯と引き継ぎメモ: [CLAUDE.md](CLAUDE.md)

```
core/              エンジン非依存の C++17 ライブラリ(rvrm): VRM 解析・座標変換・リターゲット・
                   CPU スキニング・SpringBone・一人称表示。単体テスト付き
tools/vrm_inspect  VRM の中身・利用許諾の表示、OBJ 書き出し、処理時間の計測
mod/RamenVRM       UE4SS の C++ MOD(ゲームとの接点だけを持つ)
ue/                専用マテリアル: UE 5.7 のコンテンツ用プロジェクトと、生成・pak 化のスクリプト
scripts/           install.bat / uninstall.bat / ramen_vrm_setup.ps1 / make_package.ps1
third_party/       cgltf(MIT)、同梱する UE4SS の情報とライセンス(MIT ほか)
```

ビルドには Visual Studio 2022 以降・CMake・Rust(UE4SS 用)・UE 5.7(専用マテリアル用)が必要です。
UE4SS のソースは同梱する UE4SS.dll と同じコミットのものを `external/` に取得します(Epic Games と GitHub のアカウント連携が必要)。
